# 译镜 v0.9.0

提供 Android 0.9.0 屏幕版 / 完整版，以及 Windows 0.1.0 x64 便携版。

| 文件 | 大小 | 用途 |
| --- | ---: | --- |
| `Lens-Translate-0.9.0-screen-arm64-v8a-debug.apk` | 18.21 MiB | ARM64，屏幕翻译 |
| `Lens-Translate-0.9.0-full-arm64-v8a-debug.apk` | 20.06 MiB | ARM64，屏幕与输入翻译 |
| `Lens-Translate-0.9.0-screen-armeabi-v7a-debug.apk` | 16.24 MiB | 32 位 ARM，屏幕翻译 |
| `Lens-Translate-0.9.0-full-armeabi-v7a-debug.apk` | 18.09 MiB | 32 位 ARM，屏幕与输入翻译 |
| `Lens-Translate-0.1.0-x64.exe` | 130.62 MiB | Windows 10 / 11 x64 |

屏幕版和完整版都支持全屏 / 区域翻译、悬浮球、黑底文字覆盖、本机 OCR、离线 / 自动 / DeepSeek 引擎。完整版另含译镜键盘、全拼、九宫格、笔画和本地词库联想，键盘翻译固定离线。

两版独立安装，设置、Key、历史和语言包分别管理。同包名、同签名的版本可覆盖升级。离线语言包需要首次联网下载；本应用不附带公共 API Key。Windows 使用系统 OCR 与 DeepSeek，暂不支持离线翻译。

本次标记为预发布版：Android 使用开发测试签名，Windows EXE 未做生产代码签名。当前不含手写、语音和个人词库学习；受保护窗口可能无法截屏，跨应用效果受宿主和系统限制。APK 大小不等于安装后的总存储占用。

附件与发布清单逐一核对 SHA256，校验值见 `SHA256SUMS.txt`。

项目自身代码采用 Apache-2.0，见随附 `LICENSE` 和 `NOTICE`。第三方词库保留各自许可证：拼音 Apache-2.0、笔画 LGPL-3.0。
